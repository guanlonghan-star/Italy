# Sophie 的意大利旅行路线 PWA

## 上传到 GitHub Pages

1. 新建一个 GitHub 仓库，例如 `ItalyTravelPlan`。
2. 把本文件夹里的所有文件上传到仓库根目录，不要只上传 `index.html`。
3. 打开 **Settings > Pages**，选择 **Deploy from a branch**。
4. 分支选 `main`，目录选 `/ (root)`，保存后等待发布。

## 保存成手机 App

- iPhone：用 Safari 打开网址 > 分享 > 添加到主屏幕。
- 安卓：用 Chrome 打开 > 菜单 > 安装应用/添加到主屏幕。
